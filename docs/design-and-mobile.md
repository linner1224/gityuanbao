# Git源宝每日 AI 资讯分享：设计与移动端规范

## 设计方向

界面采用“AI 情报终端”而不是通用资讯卡片模板：深海军蓝作为稳定底色，信号青用于来源与状态，状态黄只用于当前项和主要操作，粉色仅标识海外来源。标题使用粗重中文无衬线字体，正文保持 14–16px 和较宽行距。视频负责环境氛围，文字始终拥有独立深色衬底。

内容层级固定为：来源与新鲜度、标题、摘要、来源透镜、原文入口。页面不依赖新闻配图，无图内容仍有完整结构。

## 页面结构

1. 品牌栏：源宝头像、站点名称和桌面导航。
2. 首屏：值班播报与主 IP 展示；手机端上下排列。
3. 今日工作台：5 条速览、阅读进度与信号雷达。
4. 筛选区：搜索、来源、时间范围和隐藏已读。
5. 资讯列表：桌面三列，手机为来源信息在上、标题与外链并排的单列阅读流。
6. 页脚：来源说明和返回顶部。

## 响应式断点

- 981px 以上：首屏和今日工作台均为双栏。
- 761–980px：保留双栏，但压缩标题到 40–48px，避免中文单字断行。
- 640–760px：首屏和工作台改为单列。
- 639px 以下：12px 页面安全边距；源宝形态改为 48px 横向滑动带；筛选区为两列紧凑布局。
- 359px 以下：来源透镜改为单列，速览上一条/下一条按钮平分整行。

## 移动端降级策略

- 正常模式保留固定全屏视频；系统开启“减少动态效果”或省流量模式时暂停视频并使用海报背景。
- 指针倾斜仅在精确指针设备启用，触屏不运行相关监听。
- 7 张角色选择图使用 160×160 缩略图，总体积约 70KB；选中后才加载对应大图。
- 源宝选择带支持横向滑动和自动居中，露出下一项边缘提示还可继续滑动。
- 所有可见按钮、链接、输入框和选择框的触控区域不小于 44×44px。
- 筛选区在手机端退出吸顶，避免占用阅读高度；搜索全宽，来源与隐藏已读并排，时间范围全宽。
- 来源透镜通过点击打开，不依赖 hover；320px 下改为单列展示。

## 必测状态

- 320px、375px、414px、768px 和桌面宽度均无水平溢出。
- 正常动效、减少动画、视频暂停和省流量状态。
- 角色横滑到首项与末项，末项应自动进入可视区域。
- 来源透镜展开、筛选无结果、已读隐藏、分页末页。
- 所有可见交互目标至少 44px，键盘焦点清晰可见。
