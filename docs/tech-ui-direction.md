# Git源宝每日 AI 资讯分享科技感 UI 方向

## 设计主题

主题为 AI 信号观测台。页面将新闻采集理解为从持续变化的信息流中识别有效信号，因此视觉结构使用时间轴、扫描线和数据刻度，而不是通用科技产品的渐变卡片。

## 视觉令牌

- 深空蓝 `#071522`：页面背景
- 仪表蓝 `#0D2336`：输入区和数据区域
- 信号青 `#55D6E2`：正常状态及主要操作
- 离子紫 `#8D7CFF`：次级信号
- 告警黄 `#F2C45C`：异常和重要提示
- 雾白 `#DCE8F1`：主要文字

## 字体

- 标题与正文：Segoe UI Variable、Microsoft YaHei UI、系统无衬线
- 数字：Bahnschrift SemiCondensed，用于统计值和时间
- 不使用等宽字体堆叠小标签，避免模板化终端界面

## 布局

首屏是唯一高视觉强度区域，用扫描视窗表达持续采集。统计信息嵌在同一观测区域内，不使用独立悬浮卡片。筛选和新闻列表转为平直的时间序列，来源、时间、标题和操作形成稳定列。

```text
品牌 ─────────────────── 数据状态 / 最新资讯

┌────────────── 信号扫描视窗 ──────────────┐
│ 把今天的 AI 信号从噪声里分离出来          │
│ 简短说明                  收录 / 来源 / 今日 │
└──────────────────────────────────────────┘

搜索字段          来源字段          时间范围
──────────────────────────────────────────
时间  来源        标题与摘要               操作
```

## 设计约束

- 动效只使用一条慢速扫描线，并响应减少动画偏好。
- 结构线表示时间轴、字段边界或数据状态，不作为无意义装饰。
- 不使用暖米色与陶土橙组合，不使用纯黑与荧光绿组合。
- 不使用大量圆角卡片、统一阴影和英文全大写眉题。
- 文案直接说明动作，例如“浏览今日资讯”“复制链接”。

## 本轮范围

本轮仅确定桌面端视觉方向与信息结构。移动端专项重排、触控验收和窄屏截图在桌面设计确认后进行。
