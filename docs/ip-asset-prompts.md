# Git源宝网站资产生成提示词

生成时请上传 `Git源宝IP形象_透明底.png` 作为角色参考，并要求严格保持白色像素猫、黑色墨镜、粉色耳朵和黄色 Git源宝标牌等核心识别元素。

## 1. 浏览器 favicon

```text
以参考图中的“Git源宝”白色像素猫为唯一角色，制作极简浏览器 favicon。只保留猫头、黑色墨镜和粉色耳朵三个核心识别元素，不要身体，不要黄色标牌，不要文字。正面视角，轮廓粗而清楚，像素艺术风格，深海军蓝描边，透明背景，图形居中并占画布 78%，四周保留一致安全边距。在 16×16、32×32 和 64×64 像素下仍能清楚辨认。输出 1024×1024 PNG，透明底。

负面要求：不要写实毛发，不要渐变背景，不要复杂机械零件，不要细小文字，不要阴影，不要裁切耳朵，不要改变墨镜造型。
```

建议输出后缩放为 `favicon-32.png`、`favicon-180.png`，并保留一份 512×512 的应用图标。

## 2. 社交分享预览图（Open Graph）

```text
以参考图中的“Git源宝”白色像素猫为主角，制作科技新闻网站的横版社交分享封面，比例 1200×630。源宝位于右侧约 38% 区域，正面巡视姿态，保留黑色墨镜、粉色耳朵和黄色 Git源宝标牌；背景是深海军蓝 AI 情报控制室，只有青色信号线和少量黄色状态灯。左侧 55% 保持安静、低细节、深色，预留标题排版区域。画面具有像素艺术与现代科技编辑设计结合的感觉，主体清晰，背景轻微虚化，整体高对比但不刺眼。

不要生成任何文字，标题“Git源宝每日 AI 资讯分享”后续由网页或设计软件叠加，避免乱码。

负面要求：不要紫蓝渐变球，不要多个重复角色，不要密集 HUD，不要英文乱码，不要过曝霓虹，不要改变 IP 的脸和墨镜。
```

## 3. GitHub Pages / README 项目横幅

GitHub Pages 正式地址本身不需要生成图片，发布后通常为：

```text
https://<GitHub用户名>.github.io/<仓库名>/
```

如需制作 GitHub README 横幅，可使用：

```text
以参考图中的 Git源宝为主角，制作开源项目 README 横幅，比例 1280×480。源宝位于左下角，像正在维护一座 AI 新闻信号站；画面中出现简洁的 RSS 波纹、代码提交节点和三路信号轨道，分别代表中文媒体、海外媒体和官方动态。背景为深海军蓝，信号青为主强调色，黄色只用于关键状态，构图横向、简洁、留出右侧大面积标题和网址排版空间。像素艺术角色与现代矢量信息图结合，清晰、可信、有一点幽默感。

不要生成文字或网址，由后期叠加真实 GitHub Pages 地址。

负面要求：不要 GitHub 官方 Octocat，不要伪造 GitHub Logo，不要复杂代码文字，不要多角色拥挤，不要紫色渐变，不要写实 3D。
```

## 4. 404 页面插画

```text
以参考图中的 Git源宝白色像素猫为唯一角色，制作网站 404 页面插画。源宝戴着黑色墨镜，手持黄色 Git源宝标牌，正在检查一根断开的青色信号线；旁边只有一个小型“无信号”雷达圆环，表情仍然镇定可爱，不要悲伤。背景透明，角色完整，四周保留 12% 安全边距，像素艺术轮廓清晰，使用白色、深海军蓝、信号青、黄色和少量粉色，适合放在深色网页中央。输出 1600×1200 PNG，透明底。

不要生成“404”或任何文字，网页会使用真实字体叠加。

负面要求：不要哭泣表情，不要恐怖故障效果，不要复杂场景，不要裁切角色，不要额外角色，不要改变墨镜和标牌。
```
