# Git源宝每日 AI 资讯分享设计与移动端适配规范

## 设计方向

采用编辑部式资讯产品风格。深蓝用于品牌和主要操作，暖白作为阅读背景，橙红仅用于重点提示和外链动作；标题使用衬线字体强化新闻感，正文使用系统无衬线字体保证中文与英文混排清晰。

内容层级固定为：来源与时间、标题、摘要、原文入口。页面不依赖新闻图片，因此无图内容仍有完整视觉结构。

## 页面结构

1. 顶部导航：品牌、最新资讯和更新状态锚点。
2. 首屏：价值说明和资讯概况并排展示。
3. 筛选区：搜索、来源和日期范围。
4. 资讯列表：桌面端使用元信息、内容、外链三列结构。
5. 页脚：真实性说明和返回顶部入口。

## 响应式断点

- 960px 以上：首屏双栏，筛选区三列，资讯卡片三列。
- 640px 至 959px：首屏单栏，概况横向排列，筛选区三列压缩。
- 639px 以下：全部改为单列，来源和日期位于标题上方。
- 390px 以下：进一步缩小标题字号和页面边距，日期按钮平均分配宽度。

## 移动端规则

- 页面左右安全边距为 16px。
- 所有输入框和按钮高度不低于 44px。
- 首屏标题不超过约三行，概况卡紧随说明文字出现。
- 筛选控件按搜索、来源、日期顺序纵向排列。
- 长标题自然换行，不强制截断；摘要保持舒适行高。
- 外链箭头拥有独立点击区域，标题本身也可点击。
- 桌面端筛选区吸顶，移动端恢复普通文档流，避免遮挡阅读区域。

## 必测状态

- 正常数据、正在加载、数据读取失败。
- 搜索无结果以及一键清除条件。
- 单个来源失败但旧内容仍存在。
- 发布时间缺失、摘要缺失和超长中英文标题。
- 360px、390px、768px、1024px 和 1440px 宽度。
- 键盘焦点、触控点击和减少动画偏好。
